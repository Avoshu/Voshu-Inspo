## Priority decisions

1. **GPU media pipeline:** ComfyUI graph definitions should be versioned as reproducible workflow artifacts with explicit node versions, model download URLs, VRAM requirements, license and sample outputs. This supports the model-catalog plan without storing hundreds of gigabytes of model weights. ComfyUI's canonical owner is now `Comfy-Org`.
2. **Commander durable execution:** Compare Temporal and Inngest for retries, resumable task state, audit history and failure recovery. Cloudflare Agents is a separate edge-state option, not a substitute for local Windows desktop permissions.
3. **Voshu Compute/Host deployment:** Start with OpenTofu for declarative infrastructure and existing Proxmox workflows. Flux is conditional on a real Kubernetes adoption decision; avoid adding GitOps controllers to a Docker-only setup.
4. **Voshu One:** Electric's Postgres change streaming is worth an architecture review for shared state across clients and devices. Verify authentication, write authorization, offline reconciliation and license before selection.
5. **Inter-agent protocol:** A2A may complement Commander agent-to-agent messaging; MCP still governs tool access. Preserve distinct identity, delegation and approval boundaries.
