# Voshu Inspo

**The open-source discovery and inspiration library for Voshu.**

A curated, continuously updated index of tools, repositories, design references, and technical research. We link to original sources rather than cloning third-party repositories. Discovery is automated; adoption requires review.

## Research standards

Record source URL, purpose, category, license, language, stars, activity, and practical Voshu use. Keep human annotations separate from machine-refreshed metadata. Do not automatically install or execute discovered code. Prioritize maintainability, relevance, and quality over stars alone.

## Existing local inspiration

The archive at `F:\\PROJECTS\\INSPO` is **not yet migrated**. Inventory, preserve, verify, and obtain approval before deleting any local originals. Keep large media in suitable object storage, with references here.

## Automation

GitHub Actions performs a scheduled discovery scan and updates the catalog. A separate ChatGPT daily research scout supplies editorial discoveries. The two pipelines are complementary; they are not yet automatically synchronized.
