## Research standards

Record source URL, purpose, category, license, language, stars, activity, and practical Voshu use. Keep human annotations separate from machine-refreshed metadata. Do not automatically install or execute discovered code. Prioritize maintainability, relevance, and quality over stars alone.

## Preservation status

The 136 local top-level folders have been indexed, but local files, modified code, model weights and media have **not** been fully backed up. Do not delete local originals. Keep large media in object storage when preservation is verified.

## Automation

GitHub Actions performs a scheduled discovery scan and updates the catalog. A separate ChatGPT daily research scout supplies editorial discoveries. The two pipelines are complementary; they are not yet automatically synchronized.
